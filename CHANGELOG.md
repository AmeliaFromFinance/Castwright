## 1.0.0 (2026-11-03)

The first release.

### New

- **Overlays.** A canvas editor with layers for text, shapes, images, video, chat, alerts, events, goals, counters, timers, polls, credits, now playing, hype trains, ad breaks, giveaways, the viewer queue and custom HTML widgets. Six starting templates, style presets (including comic, neon and pixel looks), custom CSS with a full list of classes, scene-aware layers, multi-layer editing and a project-wide default font.
- **Chat.** Twitch and 7TV badges, 7TV name paints, and 7TV, BetterTTV and FrankerFaceZ emotes. Filters and highlights, mod tools (delete, timeout, ban, chat modes) and viewer cards. Messages Twitch removes disappear everywhere.
- **Alerts.** Variations with conditions, sounds, video and text to speech, a queue you can pause, skip, replay and mute.
- **Automation.** A free-form node canvas: triggers, steps, If branches, notes and frames. Searchable right-click menus, a live run trace with history, ten ready-made templates, a variable inspector and shareable `.cwactions` files.
- **Interact.** Channel point rewards and redemptions, polls and predictions, giveaways, a viewer queue and a soundboard.
- **Stream tools.** A go-live check, ad break helper, Discord go-live and end posts, stream markers and clips on a hotkey, and a summary after every stream.
- **App.** OBS control, global hotkeys, a health panel, bug reports with secrets removed, automatic backups, portable mode, one-click signed updates, themes (including high contrast), zoom from 50 to 250%, a command palette, and a local HTTP API for Stream Deck.
